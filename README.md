# Investigación II — entregables del curso

Maestría en Ciencias con mención en Inteligencia Artificial (FIIS–UNI).

**Tema:** asistente de consultas académicas-administrativas con enrutamiento predictivo.

**Caso:** Facultad de Ingeniería y Negocios, UMA (San Juan de Lurigancho).

**Pregunta:** ¿el routing predictivo mejora la relación calidad–latencia–costo frente a una estrategia fija?

Se comparan configuraciones A0–A5 (modelo base, RAG, fine-tuning si viable, RAG con herramientas de malla, estrategia compuesta fija y routing predictivo).
